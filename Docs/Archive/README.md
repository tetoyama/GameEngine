# Documentation Archive

このディレクトリは過去の実装計画・調査・Completion Reportを保存する。

Archiveの内容は**現在仕様ではない**。

## Structure

- `Steps/`: Step 11〜19、H、Mなどの実装記録
- `Migrations/`: ECS / Cullingなどの旧Migration Plan
- `Rendering/`: RHI / Shadow / RenderPipeline Graphの旧詳細資料
- `AgentOS/`: AgentOSの旧Phase / Integration / GPU資料
- `Games/`: 各Game projectの旧Plan / Progress / Runbook
- `Editor/`: Editor UIの旧Implementation Plan
- `Assessments/`: 時点評価・監査

## Why keep these files

過去の設計理由、性能調査、バグ原因、採用しなかった案を後から追跡できるようにするため。

ただし、現在のクラス名や実装順、未完了項目を確認する目的では使わない。

現在仕様は [Documentation Index](../README.md) から辿る。
